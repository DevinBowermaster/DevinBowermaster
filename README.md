### What I build

- **AI automations with a human in the loop.** Claude reads messy input (a Slack note, a form, a support session) and drafts the change. A person approves it before anything is written. Every one has tests, a sample set it must pass before a change ships, and a hard monthly spending cap.
- **Integrations with the tools small IT teams already run.** PSA and CRM sync, Microsoft 365, Slack, email, scheduled jobs on GitHub Actions.
- **Websites and local SEO.** I rebuilt our company site from WordPress to Astro and run SEO for local trades businesses.
- **Security work.** Microsoft 365 hardening, cleaning up hacked WordPress servers, and account takeover response.
